# Bloom & Stems Landing Page

A landing page for Bloom & Stems, a UK-based wellness brand selling premium dried hibiscus — petals, powder, tea, blended formulas, and a curated gift set — with a subscribe-and-save option.

## Structure

- `index.html` — page markup
- `styles.css` — styling
- `concepts/` — the three original design concepts presented for review (option-a: heritage editorial, option-b: bold botanical, option-c: modern wellness, the one in production)

## Running locally

Just open `index.html` in a browser, or serve the folder with any static file server:

```
npx serve .
```
